# 旁路文档：讨论过但暂不纳入 lat 的功能

> **性质**：本文件是**旁路（bypass）记录**，不属于正式 roadmap，也不代表任何开发承诺。
> 目的只是把"看过、讨论过、决定先不做"的功能连同理由和前置问题记下来，避免以后重复论证。
> 待前置条件满足后，再按 `07_decision_log.md` 的流程转正。

## 收纳边界（lat 的判断标准）

一个功能要进入 lat，需要同时满足：

1. **定义安全**：存在一个写成文档后同行无争议的定义（不依赖使用者的研究口径）；
2. **参数外露**：所有物理判据来自配置/CLI，代码不含隐藏默认值（M11）；
3. **能给出误差/自检**：可判读正常与异常（M12）。

凡是"定义本身就是研究选择"的量（自定义判据、需要调参凑目标、无公认公式），不进 lat。

---

## 一、明确不纳入

| 功能 | 标准形式 | 决定 | 理由 |
|---|---|---|---|
| **PMF / 平均力势** | `w(r) = -k_B T ln g(r)` | 不纳入 | 用 LAMMPS 做这件事的人本身很少；可由 RDF 结果自行后处理得到，不值得进主程序 |
| **第二维里系数 B2** | `-2π ∫ (g(r)-1) r² dr` | 不纳入 | 同上，受众小；且积分上限/口径易随体系变化 |
| **应力-应变及其衍生量**（E、ν、σ_yield、σ_max） | 单轴加载曲线线弹性段拟合 | 不纳入 | 并非一个 MD 后处理软件必须容纳的东西；应由使用者自行用 Origin 等工具拟合 |

> 说明：以上是"不该由 lat 承担"，不是"这些量没有标准定义"。

## 二、有必要做、但暂缓（待解决前置问题）

| 功能 | 判断 | 前置问题 / 阻塞点 |
|---|---|---|
| **Voronoi 配位 / 配位多面体** | 有必要 | **LAMMPS 可能已有内建功能**；需先确认是否为重复造轮子、以及结果是否与 LAMMPS 输出可比 |
| **结构因子 S(q)**（含偏 S(q)） | 有必要 | 目前**没有对标参数**，无法走 Ground-Truth Driven 回归；需先找到可靠参考实现/数据后才启动 |
| **端距（end-to-end distance）** | 有必要 | **输入/输出形式未定**：链的两端如何定义（按 `mol`/键拓扑？），选择器如何指定端点，输出成什么结构 |
| **内坐标分布（键长/键角/二面角）** | 有必要 | **"如何定位内坐标"未定**：LAMMPS 拓扑不像 GROMACS 蛋白质那样定义明确（无 residue/Rama 这类自动语义），需先确定拓扑来源与自动生成策略 |
| **序参数（order parameter）** | 有必要 | **需要方法学调研**：熔盐、玻璃等不同体系是否使用同一套通用算法（如 Steinhardt Q_l、四面体序参），还是各自需要不同定义 |

---

## 三、结论

- 上述"暂缓"项的共性是：**功能的科学定义可能没问题，但工程输入/对标/通用性尚未澄清**，
  因此不适合在当前阶段直接实现。
- 在条件满足前，保持旁路状态；不在版本计划内，不阻塞任何已完成模块。
