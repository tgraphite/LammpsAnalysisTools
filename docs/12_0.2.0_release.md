# LAT 0.2.0 发布说明（2026-10）

相对 0.1.0 的**行为变更**、**新增/删除**与**验收证据**。逐条对应 `docs/07_decision_log.md` §7。

## 1. 修掉的缺陷（会改变数值）

| # | 缺陷 | 影响面 | 证据 |
|---|---|---|---|
| 1 | `Bonds` 段引用的是 **atom id**，Atoms 段不按 id 排序时键表没有跟着重排 | `gyrate` / `rms` / `hbond`（凡 `make_whole` 的都受影响）| OVITO 写的 PET：6476 条"键"只有 880 条是真的；Rg 高估 3.60×、RMSD 3.50×、RMSF 4.53×。修复后对 gmx 差 3e-4/1e-4/7e-4 Å。`tests/unit/test_bond_atom_order.py` 在旧代码下必失败 |
| 2 | `hbond` 把任何带 H 的重原子当给体（C–H 也算）| `hbond` 全部输出 | 与 `gmx hbond` 对拍：PET 上 41.7 vs 4.3 每帧；修正后 6.6028 vs 6.6168（0.21%）。gmx 对纯 C 给体组直接报 `No Donors found` |
| 3 | `sasa` 不用 PBC（裸 `cKDTree`）| `probe -mode sasa` → `lat sasa` | PET 体系 0.1.0 偏高 **+14.24%**；0.2.0 为 −0.17%（frame 0）、−0.83%（frame 1）|
| 4 | PSD：距离变换不周期、bin 宽随数据变、不作体积归一、局部极大按平台计数、只用第 0 帧 | `probe -mode psd` → `lat freevol -mode psd` | 0.1.0 积分 1.5e-4、实测 bin 宽 0.944 Å 而头部写 0.5、主峰 0.055 Å 是离散化伪影；0.2.0 积分 = 1（PET 34 Å 半径、741 个孔心）|
| 5 | connectivity 不闭合环面、free 侧默认 6 邻接、逐帧输出全部分量 | `probe -mode connectivity` → `lat freevol -mode connectivity` | PET：分量 165 → 35，最大分量占比 0.99989 一眼可读；旧表 8 万行里 112 个是单体素粉尘 |
| 6 | `contact` / `residence -mode center` 直接对 wrapped 坐标求平均 | 这两个模块的 `com_dist` / 绑定计数 | 平移不变性测试：旧代码 `com_dist` 4.0 Å vs 真值 6.0 Å。修正后与 `gmx distance`（`com of group`）差 0.0097 Å |
| 7 | `pistack` 环心/法向用裸坐标 | `pistack` | 平移不变性测试旧代码计数 0 vs 1 |
| 8 | `agg` / `cluster -mode center` 用"首原子 MIC"求质心 | 长于半盒的分子 | 同一 bug 类；`_graph._coms` 改走 `residue_coms` |
| 9 | `hbond` 连续自相关 O(T²) 次 numpy 调用 | 长轨迹（≥500 帧）+ 大体系 | 24 号体系 601 帧：帧循环 420 s 完成后卡在 ACF 30+ 分钟；改为增量式（并丢弃已结束的氢键对）后数学完全等价，120k 对 × 601 帧由分钟级降到 **0.04 s**；`tests/unit/test_hbond.py` 用朴素定义逐位对拍 |
| 10 | `bond_graph_consistent`：键图跨盒环绕时**拒绝**给数（而不是给一个位移 23 Å 的质心）| `contact`/`residence -mode center`、`gyrate`、`rms` | 24 号体系的石墨烯层（960 原子、二维周期共价网络）上，整分子重建把质心挪了 **23 Å**；现退回 wrapped 质心 + WARN。gmx 对同一体系**直接报错**（`inconsistent shifts over periodic boundaries`）|

## 2. 新增 / 删除

- **新增** `src/lat/core/periodic.py`：周期几何唯一入口（分子 / 原子对 / 体素网格 / 曲面四层）。
- **新增** `lat freevol -mode {ffv,psd,connectivity}`（默认 `ffv`）与 `lat sasa`。
- **删除** `lat probe`（**无兼容壳**）；`porosity` 与 `ffv` 数值相同故不再作为独立模式；
  网格模式不再接受 `-sel`（0.1.0 收下后静默忽略）。
- **新增测试**：`tests/unit/test_periodic_core.py`（22 项）、`tests/unit/test_no_ad_hoc_pbc.py`（架构守卫）、
  `tests/unit/test_config_sync.py`、`tests/regression/level2_format/test_pbc_invariance.py`（平移不变性）。
- `lat --version` → **0.2.0**；`config/lat.yaml` 与 `src/lat/data/lat.yaml` 逐字节相同（由测试保证）。

## 4. 硬错误取代静默近似

- `freevol` 网格：三斜盒 → 报错；所选帧内盒漂移 >2% → 报错；0.1%–2% → WARN 且网格钉在首帧。
- `contact`/`residence -mode center`：选区非整分子且质心歧义 >0.1 Å → WARN（报出歧义大小）。
- `sasa`：选区为空、元素无法推断 → 报错。
- `hbond`：`-sel1` 内没有电负性 H → 报错（与 gmx `No Donors found` 一致）。

## 6. 已知残留（明确声明，不算通过）

- `gyrate -sel all` 在多分子周期体系里不是良定义量（周期像歧义可达 17%，`MANUAL_ALGORITHMS.md` §4）。
- `msd` / `transport`：位移接近半盒时依赖解包坐标，dump 无 `ix/iy/iz` 或 `xu` 时只给 WARN。
- `hbond` 的选择语义与 gmx 不同（lat 的 `-sel1` 是给体组，gmx 在两组之并集内识别给体/受体，
  统计两组之间的氢键）——见 `MANUAL_ALGORITHMS.md` §17。
- `contact`/`residence -mode center` 用几何质心（gmx 的 `com of group` 是质量加权），实测差 0.01 Å。
- **`hbond` 的受体集合比 gmx 宽**（lat 含 F/S/Cl/Br/I，gmx 只认 O）：含 Cl⁻ 的体系 lat 计数比
  `gmx hbond` 高 **+13.8%**（24 号体系），水/表面活性剂体系 +0.7%，纯 C/H/O 体系 +0.21%。
  化学上 lat 更完整；要逐值对齐需要一个 `-acceptors gmx` 开关（未实现）。
- 二维周期共价网络（电极片层、凝胶）无法做整分子复原：`contact -mode center` 退回 wrapped 质心 + WARN，
  `gyrate`/`rms` 加 WARN；gmx 在同样情形直接报错。
- PSD/connectivity 是体素网格近似，不是 Zeo++ 的 Voronoi 几何算法。
