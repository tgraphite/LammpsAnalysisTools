# 01 · 元要求（M1–M15）与范围

> 元要求的目标：在不显著增加复杂度、不产生元冲突的前提下，保证工具的**正确性、可复现性、易用性、可回归性**。
> 标 [必须] 者为硬约束；[低成本] 为低代价高收益；[防冲突] 为边界纪律。

## 元要求

| # | 要求 | 说明 | 状态 |
|---|---|---|---|
| M1 | **[必须] 单位显式化** | **LAMMPS 的 data/dump 文件都不携带 units 信息**（units 是 input script 命令）。默认长度单位 **Å**（real/metal 皆是）；未显式给 `-unit` 时按默认并报 **INFO**（不中断）。输出 header 标单位。不做自动魔法 | 确认 |
| M2 | **[必须] 时间=帧号** | 所有 `frame_range` 为帧区间；忽略 LAMMPS 时间；寿命/滞留以帧输出，header 标注「k × 帧间距」；`frame_interval` 仅用于换算展示 | 确认 |
| M3 | **[必须] 拓扑不强推断** | 不推断分子/残基；用户运行前用静态 MDAnalysis 语义或 `ndx` 指定目标；无交互输入 | 确认 |
| M4 | **[必须] 三斜盒 + PBC** | 所有距离支持 triclinic minimum image；分子内排除依赖用户显式给出的分子定义 | 确认 |
| M5 | **[低成本] 可复现** | 全局 seed；debug 记录 seed/sha256/版本；**成品不向用户暴露无关审计信息** | 确认 |
| M6 | **[低成本] 内部输出契约** | `Table(scalars, fields, units)` 对象 → 序列化；一文件一表、多字段共 X | 确认 |
| M7 | **[低成本] 错误分级** | FATAL/WARN/INFO + 退出码；WARN 同时进 header 与屏显 | 确认 |
| M8 | **[低成本] 原子写 + 幂等** | tmp+rename；同名默认报错，`-f` 覆盖 | 确认 |
| M9 | **[必须] 流式** | 逐帧处理，绝不全轨迹载入；声明复杂度/峰值内存；支持 stride | 确认 |
| M10 | **[低成本] `lat select`** | 打印命中数/类型分布；可导出 `ndx` 供校验 | 确认 |
| M11 | **[低成本] 配置单一来源** | `config/lat.yaml` 定义默认值/单位/模块文档/输出模板；CLI > YAML > FATAL，代码零 backup；`-h` 与文档同源 | 确认 |
| M12 | **[必须可控] 归一化自检** | RDF 的 g(r) 与 CN 自洽、密度积分=质量、MSD 拟合 R²；可关 WARN，不做隐式校正 | 确认 |
| M13 | **[低成本] 注册表 + 纯函数接口** | `module(ctx, params) -> [Table]`；新模块零核心改动 | 确认 |
| M14 | **[低成本] 计算/绘图解耦** | `plot1d`/`plot2d` 只读 CSV | 确认 |
| M15 | **[防冲突] 只做 schema 级推断** | 物理量一律显式；无自动单位/自动拓扑魔法；无全局隐式状态；与「配置错即崩」自洽 | 确认 |

## 范围（Scope）

**做**：`rdf`、`density`、`hbond`、`rms`(RMSD/RMSF)、`msd`、`agg`、`cluster`、`pistack`、
`freevol`、`sasa`、`residence`、`transport`、`occupancy`、`gyrate`、`contact`、`order`、`select`、`plot1d/2d`、`describe`。

**不做**：能量/自由能、PMF、MMPBSA、对接、反应网络、固体/金属力学、DXA/位错、SDF、谱/VDOS/SAXS、
phonon、相场、DPD/CG、AIMD/QM、PKA。

**边界纪律**：不因「顺便」而引入外部进程依赖（除已明确的 `ndx` 生成建议外）；不实现引擎的职责。

## 元冲突检查

- M1（显式单位）与 M3（不强推断）一致：都要求物理语义由用户声明。
- M2（帧号）与 M5（可复现）一致：去除了时间插值带来的不确定性。
- M6/M11/M13/M14 相互独立，无循环依赖。
- 唯一潜在冲突：M12 的「自检 WARN」可能被误当隐式校正——文档明确：**只警告，不修正**。
